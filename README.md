# ぷにフレ

好きなことから新しい人と出会える、日本語のコミュニティアプリのプロトタイプです。

## 起動方法

`index.html` をブラウザーで開くだけで利用できます。ビルドや追加の依存関係は不要です。

## 主な機能

- 趣味やキーワードによるメンバー検索
- 気になる人への「つながりたい」申請
- イベント一覧と参加登録
- メッセージ、プロフィール画面
- プロフィール情報の保存（ブラウザー内）
- 名前を入力してフレンドに追加（ブラウザー内）
- フレンドとのメッセージ送信と会話履歴の保存（ブラウザー内）
- モバイル向けレイアウト

メンバーやイベントのサンプルデータは含まれていません。プロフィールや設定、追加したフレンド、メッセージ履歴はブラウザー内に保存されますが、サーバーや他の利用者とは共有されません。名前で追加する機能は、この試作品内にフレンドを登録するもので、他の利用者のアカウントを検索したりメッセージを配信したりする機能ではありません。
